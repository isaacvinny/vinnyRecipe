# 🍳 Vinny's Recipe App

A modern and responsive recipe application built with **React.js** that helps users discover recipe ideas based on the ingredients they have available.

Users can enter one or more ingredients, and the application generates a recipe suggestion including ingredients, preparation instructions, and other useful details.

## 🚀 Live Demo

**Live Application:** [https://isaacvinny.github.io/vinnyRecipe]

## 📌 About the Project

Vinny's Recipe App was built to provide a simple and convenient way to turn available ingredients into meal ideas.

The application demonstrates the use of **React.js, API integration, state management, routing, environment variables, and responsive UI development**.

The project was also created as part of my continuous learning and practical development journey with React.

## ✨ Features

* 🔎 Search for recipes using available ingredients
* 🍽️ Generate recipe suggestions dynamically
* 📝 Display recipe ingredients and preparation instructions
* 📱 Fully responsive design for desktop, tablet, and mobile devices
* 🧭 Client-side navigation using React Router
* ⚡ Fast development and build process with Vite
* 🔐 API key stored securely using environment variables
* 📖 Markdown rendering for formatted recipe instructions
* 🎨 Clean and user-friendly interface
* ⏳ Loading and error handling for API requests

## 📖 How It Works

1. The user enters one or more ingredients into the input field.
2. The application captures the user's input using React state.
3. The ingredients are sent to the recipe-generation API.
4. The API processes the ingredients and generates a recipe.
5. The generated response is returned to the application.
6. React Markdown formats the recipe content for easier reading.
7. The recipe is displayed to the user through the application interface.
